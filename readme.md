 # 📁 File Organizer Pro

Un pratico script Python per **organizzare automaticamente i file** in una cartella,  
suddividendoli per **tipo di file** o **data di modifica**.

Progettato per risparmiare tempo, ridurre il caos digitale e aiutarti a mantenere ordine nel tuo sistema!

---

##  Funzionalità

-  Organizzazione automatica per **tipo di file** (immagini, PDF, documenti, ecc.)
-  Organizzazione automatica per **data** (crea cartelle con la data dell'ultima modifica)
-  Sicuro: non elimina nulla, solo riordina
-  Logica semplice, codice pulito, facilmente modificabile
-  Include ASCII art per fare scena nel terminale 😎

---

##  Requisiti

- Python 3.x
- Nessuna libreria esterna necessaria

---

##  Utilizzo

1. Clona il repository o scarica `organizer.py`
2. Avvia lo script:
   ```bash
   python organizer.py


3. Inserisci il percorso della cartella da organizzare
4. Scegli se ordinare per:
   - `T` (Tipo)
   - `D` (Data)

---

##  Note

- Testato su sistemi Windows e Linux
- Eseguire su copie di backup se non sei sicuro del contenuto
